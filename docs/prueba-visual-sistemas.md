# Prueba visual para Janco

Objetivo: demostrar que Janco entiende y resuelve la operación de una
arrendadora. Cada pieza debe enseñar un flujo real, no solo una pantalla bonita.

## Reglas antes de publicar

- Usar datos de demo o información completamente anonimizada.
- Ocultar clientes, placas, teléfonos, correos, RFC, importes sensibles y documentos.
- Evitar marcas de terceros que no deban aparecer públicamente.
- Preferir pantalla completa limpia, sin barra del navegador ni notificaciones.
- Exportar imágenes en `.webp` o `.png` y videos en `.mp4`.
- Mantener cada video entre 30 y 75 segundos.

## Capturas prioritarias

- Dashboard de dirección con cartera, contratos y cobranza.
- Cliente con cotizaciones y expediente.
- Contrato con anexos y activos relacionados.
- Facturación con calendario de rentas.
- Cobranza con vencimientos, pagos y seguimiento.
- Activo con GPS, documentación, seguros o multas vehiculares.
- Reporte de cartera para dirección.

## Recorrido recomendado para video

1. Abrir un cliente de demostración.
2. Revisar una cotización.
3. Entrar al contrato, anexos y activo relacionado.
4. Mostrar la renta, factura y pago.
5. Revisar un vencimiento en cobranza.
6. Cerrar con un reporte de cartera o dirección.

## Dónde integrarlas

- Portada, dentro de la explicación del producto o la demo.
- `sistemas/arrendamiento-puro.html`.
- Artículos donde la captura aporte evidencia directa al tema.

La galería ideal combina una captura principal, dos capturas secundarias y un
video corto. Todas las leyendas deben explicar qué decisión o tarea facilita la
pantalla mostrada.
